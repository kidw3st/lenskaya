# ЖК Ленская — Премиальный сайт жилого комплекса

Премиальный имиджево-продающий сайт жилого комплекса бизнес-класса «Ленская» в Перми.

## О проекте

Создан по техническому заданию на проектирование и разработку премиального сайта жилого комплекса бизнес-класса. Комплект расположен на первой линии правого берега реки Камы в Перми.

### Ключевые особенности:
- **709 квартир** бизнес-класса от студий до 3-комнатных
- **Террасная архитектура** с панорамными видами на Каму
- **Приватные дворы** без транзитного трафика
- **Зелёные коридоры** между Закамским Бором и набережной

## Функционал

### Страницы:
- **Главная** — имиджевая презентация с hero-блоком, преимуществами, архитектурой, расположением, превью квартир и галереи
- **Квартиры** — каталог с фильтрами (комнатность, площадь, этаж, стоимость, корпус, статус)
- **Детальная карточка** — полная информация о квартире с галереей, параметрами и CTA
- **Избранное** — сохранённые квартиры (localStorage)
- **Галерея** — визуализации с фильтрацией по категориям
- **Расположение** — карта, окружение, сценарии маршрутов
- **Контакты** — офис продаж, форма обратной связи, мессенджеры
- **Юридическая информация** — политика конфиденциальности, согласие на обработку данных

### Интерактив:
- Фильтрация квартир без перезагрузки
- Система избранного (localStorage)
- Формы с валидацией и маской телефона
- Модальные окна для консультаций и получения презентации
- Адаптивный дизайн (mobile-first, от 320px)
- Анимации при прокрутке
- Sticky header с изменением при скролле
- Мобильное меню
- Всплывающие уведомления (toast)

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — современный CSS с переменными, Grid, Flexbox, анимациями
- **JavaScript** (ES6+) — Vanilla JS без фреймворков
- **Google Fonts** — Playfair Display + Inter
- **SVG** — векторные иконки

## Запуск

### GitHub Pages
Сайт автоматически развёрнут на GitHub Pages:
**https://kidw3st.github.io/lenskaya/**

### Локальный запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/kidw3st/lenskaya.git
   ```
2. Откройте `index.html` в браузере

Или используйте локальный сервер:
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```
