# ЖК Ленская — Премиальный сайт жилого комплекса

Архитектурный квартал на правом берегу Камы. Сайт бизнес-класса с кинематографичной подачей.

**Демо:** https://kidw3st.github.io/lenskaya/

## О проекте

Многостраничный премиальный сайт жилого комплекса бизнес-класса в Перми. Создан по ТЗ на UX/UI-дизайн с референсами: Dius, Akvilon Stories, Prospect Mira, Forst.

### Ключевые особенности:
- **709 квартир** бизнес-класса от студий до 3-комнатных
- **Террасная архитектура** с панорамными видами на Каму
- **Приватные дворы** без транзитного трафика
- **Зелёные коридоры** между Закамским Бором и набережной

## Дизайн

- **Палитра:** лесной зелёный (#1B3A2D) + золото (#C4A265) + кремовый (#FDFBF7)
- **Типографика:** Playfair Display (заголовки) + Inter (текст)
- **Стиль:** архитектурный журнал, минимализм, кинематографичность

## Компоненты

- **Интро** — цифровая заставка при первом посещении (сессионное хранение)
- **Лайтбокс** — полноэкранный просмотр с навигацией и свайпом
- **Быстрый подбор** — фильтры на hero-экране
- **Нумерованные секции** — как в архитектурных журналах
- **Горизонтальный скролл** — для инфраструктуры и галереи
- **Мобильная панель** — 5 кнопок: звонок, Telegram, квартиры, избранное, заявка
- **Floating-кнопка** — быстрая связь
- **Формы** — валидация, маска телефона, localStorage

## Технологии

- HTML5, CSS3 (Grid, Flexbox, переменные, анимации)
- Vanilla JavaScript (ES6+)
- Google Fonts (Playfair Display + Inter)
- SVG-иконки
